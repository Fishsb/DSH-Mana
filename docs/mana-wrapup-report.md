
⇒ **唯一红的那条腿，重取也消不掉**（新的 `prev` 又成了自己这条），且我早已裁定**不消它**、并补了 `kind=incident` 注解留痕。

因为该命令**会跑 A1 腿（5+ 分钟）**；而它**被杀前已把锁写成陈旧** ⇒ 第二次调用触发 `[lock takeover] 接管陈旧锁`。

**教训两条**：① **收尾时不要跑长任务**；② **动契约前先查「这个红是不是我该消的」** ——
我差点为消一个不该消的红，去冒污染流水（**append-only、不可回滚**）的风险。

**裁定：第五次重取不做。** 若将来确有需要（例清单腿真漂），应在**全席停手 + 预留 ≥10 分钟**的窗口做。
