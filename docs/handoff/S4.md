## 2bis. R2/d2 新增：slot 真注册（判据 ③ 的口径与证据）

**目标**：把面板从「无 DOM 数据面」变成**真注册进 slots 的组件**。

**判据 ③ 的口径（核心）**：不接受「代码里有 `ctx.slots(...)` 就算」。本席用
**宿主自带的真槽机制**做取证，而不是假对象：

```
$ node -e "import('/usr/local/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-ui-slots/lib/index.js').then(m=>console.log(Object.keys(m)))"
[ 'SlotCore', 'SlotOwnershipError', 'StaleAuthorizationError', 'resolveSlotLabel', 'standardHookPropName' ]
```

`SlotCore` 是 node 侧可 import 的**纯核心**（`register` / `entriesOfSlot` / 释放链路齐备），
故判据可以「注册 → 从台账读回 → 逐字比对 → 撤根 → 台账清空」，全程不依赖我自己的返回值。

**实测断言链**（`tests/ui.test.mjs` 第 11 条，原文摘要）：
- 先向 root 声明子槽 `conversation.view`，再让被测代码注册；
- `core.entriesOfSlot('conversation.view')` → **长度 1**，`options.id === 'mana-ui'`、
  `options.order === 30`、`typeof component === 'function'`（**从机制台账读回，不是信任返回值**）；
- 调用序列可枚举：`['inject','register']`，且 `inject` 的 key 与 `register` 的 `spec.name` 都是 `conversation.view`；
- 撤下根条目 → 子槽台账**清空**（释放链路真通）。

**判据 ④ 负向控制（两次，都必须变红）**：
1. **把 `slots.register` 换成空操作**后重建产物重跑 → `# pass 11 / # fail 2`，第 11、12 条**变红**
   （台账读不到条目 ⇒ 证明该判据非恒真）；
2. **注入故意抛错的槽面**（`not declared`）→ `registered === false` 且 `reason` 携带**原始报错**
   （不泛化），台账为空。

**产物侧变化**：`lib/client.js` 由 9,557 B → **19,853 B**（新增三面板渲染树 + 槽装配 + React 面探测）。
