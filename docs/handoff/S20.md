## - [x] 反证判据（负向对拍）

### ⚠ 1. 派单指定的负控①**打不出靶** —— 已在打对靶后成立（**本条是本席最重要的发现，须主持人裁决**）

派单字面写「**按 `方案` §6.4**（一行三字）」并给出负控「把『方案』二字删掉 ⇒ C16 必红」。实测**删掉后 C16 不红**：

```
①-a 加粗形式(**方案**) 删「方案」二字节 | exit=0 | PASS [C16] ... （未报红 ⇒ 负控打不出靶）
①-b 无粗体(方案)     删「方案」二字节 | exit=1 | ✗ [C16] L185 指向本册 §6.4，但本册无此小节
```

**成因**（已读判据器源码定位）：`docs/_check-consistency.mjs:358` 的 C16 检测正则为
`/(?:见|读|跳|按|回|阅)\s*(?:本册\s*)?§(\d+(?:\.\d+)*)/g` —— 它要求 **「§」紧跟在触发词（或「本册」）之后**。写 `**方案** §6.4` 时触发词「按」与「§」之间夹了 `**方案** ` ⇒ 该正则**完全看不见这条引用**，C16 于是因「无引用可查」而 PASS，即**判据被致盲**而非问题被解决（正是本仓「判据绿 ≠ 事实被检查」）。

**本席采用 `按方案 §6.4`（无内部加粗）**：

1. **负控①在打对靶下成立**（上一行 ①-b，`exit=1`、报红文本逐字命中 `L185`）；
2. 与同行 `:187` 的**既有房内写法逐字同形**（`> 方案 §6.4 的「批量」指的是…`）⇒ 不引入新风格；
3. 「一行三字」的改动量不变。

**就地扰动 → 必红 → 逐字节恢复**（真文件上做，窗口 113 ms）：

