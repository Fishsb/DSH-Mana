### 4. ⚠ 实测出的判据盲区（本席本轮最该被看到的一条）

| 扰动 | 扰动生效？ | 探针读出 | A0-8 门判 |

**必须改夹具的原因（不是"为了变绿"）**：L-00 之前夹具用手写 `ALTER TABLE ADD COLUMN` 模拟"已补列"。

更关键：手写 ALTER 验的是"**手写 SQL 能补**"，而不是"**本仓补列机制能补**"——靶子本身就错了。
改后补列由 `createSchema` 真跑，夹具不代劳。
