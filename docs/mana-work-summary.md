### 3.1 并行上限的硬约束（实测）

| 约束 | 实测 |
|---|---|
| **判据器单实例锁** | `a1=exit 4` / `a0=exit 3`，且**不排队** ⇒ 每席跑门会互相空转 |
| **产物内容腿** | 每次重编译 ~13 s，且要求 src/lib 一致 ⇒ 改 src 必重建 |
| **基线重取** | 要求**全席停手**才能完整归因（第四次重取就是在那个窗口做的） |
| **顶层构建** | 禁 workspace 级 build（会把他席在途码编进产物） |

⇒ **可行的并行上限 ≈ 4 席**（3 席跑码 + 1 席跑判据类），且**必须**：① 写面两两不相交；② 每席只 build 自己那包；
  ③ 遇锁等不等 kill；④ 基线重取只在收口窗口做。
